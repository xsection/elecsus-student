# GUI assets

Served by Dash from this folder (every `.css` here is added to the page), so
the GUI renders the same with no network connection.

| File | What | Licence |
|---|---|---|
| `bootstrap-flatly.min.css` | Bootswatch 5.3.6 "Flatly" theme (Bootstrap 5.3.6), the theme `dbc.themes.FLATLY` points to; its Google Fonts `@import` of Lato is removed, since the GUI sets Inter | MIT: `LICENSE-Bootswatch.txt`, and the Bootstrap notice in the file header |
| `elecsus.css` | GUI adjustments: hides Dash 4's number-input stepper buttons, which truncated the values | Apache-2.0, as ElecSus |
| `inter.css`, `inter-latin-*-normal.woff2` | Inter, weights 400/500/700, latin subset (@fontsource/inter 5.3.0) | SIL OFL 1.1: `LICENSE-Inter-OFL.txt` |
